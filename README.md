# NWC Faculty Workbench

The NWC Faculty Workbench is a public-safe markdown toolkit for designing, assessing, reusing, and governing AI-enabled professional military education.

It is not an essay companion and not a website. It is a faculty implementation surface: practical worksheets, rubrics, source-kit templates, flawed-output patterns, calibration protocols, and future context-curation guidance.

The workbench grew out of the argument in **The Irreducible Officer**, but it should stand on its own. Faculty can use it wherever the instructional problem is the same: students need to use AI without surrendering purpose, frame, reliance, accountability, or judgment.

## What This Is For

- Design assignments that deliberately sequence AI-free and AI-mediated work.
- Preserve developmental friction where judgment forms.
- Make purpose, frame, reliance, accountability, and transfer visible.
- Build reusable flawed outputs, rubrics, oral-defense questions, and source kits.
- Help faculty teams calibrate judgment against the same artifact.
- Mark which capabilities are ready now as markdown templates and which belong to future institutional infrastructure.

## What This Is Not

- It is not the public AI companion.
- It is not a website source repo.
- It is not an institutional memory system yet.
- It is not a secure NWC deployment plan.
- It is not a replacement for faculty judgment.
- It is not a prompt-log compliance regime.
- It should not absorb private course material into a public repo.

## Start Here

**With an AI assistant (recommended):** give your assistant the [workbench source kit](workbench-source-kit.md) — or the full workbench bundle from the public site (https://judgmentlab.net/assets/workbench-context.md) — and say: "Run the phase placement diagnostic with me." The assistant will place your assignment on the fluency progression and route you to the right template. Every template contains an AI Facilitation Block, so the assistant can run it as a guided session.

## Maturity Levels

### Level 1: Faculty Fluency Lab

Faculty practice AI-enabled strategic work themselves before teaching or assessing it. This can happen through essay critique, prompt deconstruction, oral-defense rehearsal, or a real course artifact.

### Level 2: Assignment Design

Faculty decide where AI belongs in the learning sequence, what work should happen before AI enters, what AI should challenge or expand, and what final human judgment students must defend.

### Level 3: Assessment Design

Faculty define what evidence of ownership they need to see: purpose through frame, reliance decisions, accountability for judgment, and transfer to a changed case.

### Level 4: Flawed Output Library

Faculty build a reusable set of polished but strategically flawed AI outputs. The point is to train students to see beneath fluency.

### Level 5: Faculty Calibration

Faculty compare how they diagnose the same AI-assisted work, record points of agreement and disagreement, and revise rubrics or oral-defense criteria.

### Level 6: Source Kits

Faculty package the context for an AI-enabled exercise. A source kit is not a file dump. It tells an AI assistant what sources matter, what standards apply, what outputs faculty will inspect, and where public/private boundaries sit.

### Level 7: Institutional Memory

Future direction. Faculty preserve lesson rationale, rubric changes, after-action notes, recurring student failure modes, and source-kit evolution across rotations.

### Level 8: Context Curation And Operational Sandbox

Future direction. A Librarian-style architecture could support a faculty-governed context vault, proposal queue, handoffs, diffs, and rollback. This is a reference pattern, not a current NWC implementation claim.

## Future Direction

The future workbench could become an institutional context system. That would require security review, governance, faculty ownership, versioning, and clear approval paths before any student or faculty artifact becomes shared institutional context.

The design principle is simple: AI assistants can propose, organize, compare, and retrieve. Faculty approve what counts.
