# Facilitation Transcripts

Worked examples of templates being facilitated by an AI assistant.

## The Habit

Before a template's facilitation block is considered ship-ready, run it through at least two different assistants (for example ChatGPT and Claude) as a realistic faculty session. Keep one good transcript per template here, named `<template-name>--<assistant>.md`.

Scrub before committing: no private course material, no student names, no account details. Transcripts are teaching examples, not compliance records.

## Smoke Tests Versus Transcripts

A simulated run — one AI playing the assistant, another party scripting the faculty member — is a smoke test, not a transcript. Smoke tests gate prompt mechanics before a path reaches a person: does the assistant load the full bundle (require a proof-of-read check, such as counting the bundle's sections), follow the facilitation block, and keep judgment with the human. They do not count toward the two-assistant ship-ready habit above. Label any saved smoke test as simulated.
